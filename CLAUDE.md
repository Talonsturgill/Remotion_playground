# Project Instructions for Claude

## Video Creation

Whenever the user asks to "make a video", "create a video", "generate a video", or anything related to video creation, you MUST use the Remotion skill located at `.claude/skills/remotion.md`.

Read and follow the Remotion skill guide to:
1. Set up a Remotion project if one doesn't exist
2. Create React components for the video
3. Use Remotion's animation helpers (interpolate, spring, Sequence)
4. Help render the final video

## Project Context

This is a Remotion playground project for creating programmatic videos using React and Remotion.
